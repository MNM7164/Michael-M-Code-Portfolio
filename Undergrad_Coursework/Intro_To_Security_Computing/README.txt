Treasure Hunt Game - CYBV 310
=============================

Author: Michael Masterton
Language: C (Standard Libary Only)
Assignment: Assignment 4 Treasure Hunt Game

=============================
    BUILD INSTRUCTIONS
=============================

Using GCC (MinGW, Linux, macOS):

    gcc treasure_hunt.c -o treasure_hunt

Run With:

    treasure_hunt.exe   (Windows)
    ./treasure_hunt     (Linux/Mac)

No extra libraries needed.

=============================
   CONTROLS & RULES SUMMARY
=============================

Controls:
    Standard Gaming Mechanics:
    W - Up
    S - Down
    A - Left
    D - Right
    Q - Quit

Rules:
    1. You start at the top-left of the 10x10 Grid/Map.
    2. Treasure ($) and traps (T) are randomly placed.
    3. Collect treasures to increase your score.
    4. If you step on a trap, the game ends immediately. 
    5. Fog of War (FOW):
        5.1 ? = Never seen
        5.2 . = Seen before and unoccupied
        5.3 Visible tiles show:
            5.3.1 P = Player
            5.3.2 $ = Treasure
            5.3.3 T = Trap
            5.3.4 . = Explored and/or Unoccupied
    6. Win when all the treasures are collected.
    7. Borders prevent out of bounds movement.

=============================
DESIGN CHOICES AND ASSUMPTIONS
=============================

1. Fixed grid size (10x10) per assignment instructions.
2. No dynamic memory allocation.
3. Random placement avoids overlap with player, traps, and treasures.
4. Movement and logic kept modular across many functions.
5. FOW uses Chebyshev distance (max(|dr|,|dc|))
6. `treasure_index_at` uses O(1) deletion by replacing found treasure 
    with the last one in the array.
7. Invalid input is safely ignored without crashing.
8. Main loop is intentionally minimal to follow the design rule.
